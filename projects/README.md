# 🚀 Projects

This directory serves as an index of real-world projects where the knowledge gained from the DevSecOps Learning Lab has been applied.

Unlike the hands-on labs, these repositories focus on solving practical engineering problems and simulate production-oriented software development. They combine concepts from multiple learning phases—including software engineering, DevOps, DevSecOps, cloud infrastructure, security, observability, and system design.

The goal is to bridge the gap between isolated learning exercises and complete, production-inspired applications.

# 🎯 Purpose

The DevSecOps Learning Lab focuses on learning individual technologies through structured experiments.

These project repositories demonstrate how those technologies come together to solve real engineering problems.

```text
Labs
        │
        ▼
Understand a technology
        │
        ▼
Practice it
        │
        ▼
Projects
        │
        ▼
Apply it in real-world systems
```

The separation keeps the learning repository focused on experimentation while allowing production-oriented projects to evolve independently.
