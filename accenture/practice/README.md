# Cybersecurity Practice and Hands-On Labs

## Overview

This directory contains practice questions, mock examinations, scenario-based exercises, and hands-on labs designed to reinforce cybersecurity knowledge.

It supports preparation for the Accenture Cybersecurity Mastery Program assessment while developing practical skills relevant to cybersecurity, cloud engineering, and DevSecOps.

## Purpose

The purpose of this directory is to turn theoretical knowledge into applied understanding.

Learners can test their knowledge, analyze realistic scenarios, practice technical tasks, and identify gaps that require further review.

## Directory Structure

### `question-bank/`

Contains original practice questions organized around cybersecurity topics.

Planned materials include:

- Multiple-choice questions (MCQs).
- Scenario-based questions.
- Answer keys and explanations.
- Topic-specific quizzes.

### `mock-exams/`

Contains timed practice examinations intended to simulate general assessment conditions.

Each mock examination should provide instructions, questions, an answer key, explanations, and a scoring guide.

These are independent practice examinations and are not actual or verified Accenture examination questions.

### `hands-on-labs/`

Contains practical exercises organized by cybersecurity domain.

Examples include:

- IAM permissions and least-privilege exercises.
- Network traffic inspection and firewall configuration.
- Linux hardening.
- Cloud security configuration and misconfiguration analysis.
- Log analysis and incident-response exercises.
- Vulnerability scanning and remediation.
- Application and API security testing.
- Container and CI/CD security checks.
- Threat modeling and security architecture exercises.

## Recommended Practice Workflow

1. Study the relevant topic in `../Concepts/`.
2. Review the material in `../Review/`.
3. Answer questions without consulting the answer key.
4. Check your answers and read the explanations.
5. Complete the corresponding hands-on lab where available.
6. Record mistakes and revisit weak topics in `../Progress/`.

## Practice Standards

- Questions should be original and educational.
- Answer explanations should explain why an answer is correct and why plausible alternatives are incorrect.
- Labs should include objectives, prerequisites, steps, expected results, and cleanup instructions where applicable.
- Security testing must be performed only in authorized, controlled environments.
- Avoid including credentials, access tokens, private keys, or sensitive information in the repository.

## Learning Objectives

- Improve cybersecurity knowledge through deliberate practice.
- Develop technical reasoning and scenario-analysis skills.
- Apply security controls in controlled environments.
- Build confidence through repeated practice and feedback.
- Identify and address weaknesses systematically.
