# Cybersecurity Review

## Overview

This directory is for concise revision notes, checklists, comparison tables, and synthesis across the domains in the [Cybersecurity Mastery](../README.md) module. Review material should make it easier to retrieve and apply knowledge after the deeper explanation in [`concepts/`](../concepts/README.md).

The current directory contains this guide only. Topic summaries and checklists are planned additions, not completed learning evidence.

## Review domains

Review material may cover:

1. Security Governance, Risk, and Compliance
2. Identity and Access Management
3. Network Security
4. Endpoint Security
5. Cloud Security
6. Security Operations and Incident Response
7. Vulnerability Management
8. Application and API Security
9. Data Protection and Privacy
10. Security Architecture and Engineering

## How to review

1. Select a topic or a weak area from [`progress/`](../progress/README.md).
2. Summarize the security objective, threats, controls, and trade-offs without copying a definition blindly.
3. Use prompts, diagrams, or checklists to test recall.
4. Validate the summary against the relevant concept notes and authoritative references.
5. Apply the idea through an authorized exercise in [`practice/`](../practice/README.md).
6. Update the progress record with the outcome and any remaining questions.

## Suggested review entry format

- Topic and status.
- Key terms and relationships.
- Threats, risks, and security objectives.
- Preventive, detective, and corrective controls.
- Operational or architectural trade-offs.
- A short scenario or question for self-testing.
- Related concept notes and practice exercises.
- Date reviewed and next review trigger.

Use `Planned`, `In progress`, `Completed`, and `Needs review` consistently. A review summary is not evidence of a completed lab or demonstrated skill by itself.
