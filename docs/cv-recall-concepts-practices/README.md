# CV Recall — Concepts & Practices

> Learn. Recall. Practice. Review. Improve.

## Overview

This workspace is dedicated to strengthening technical understanding through active recall, hands-on exercises, troubleshooting, and structured review.

It serves as a personal learning environment for revisiting concepts, practicing technical workflows, understanding implementation details, and developing stronger problem-solving skills.

## Learning Objectives

- Strengthen understanding of core technical concepts.
- Practice Docker, CI/CD, DevSecOps, cloud infrastructure, and Kubernetes fundamentals.
- Develop confidence in reading and explaining configurations and workflows.
- Improve troubleshooting and debugging skills through practical exercises.
- Reinforce learning through active recall and spaced repetition.
- Document lessons learned, mistakes, and areas for improvement.
- Practice explaining technical decisions clearly and accurately.

## Learning Method

Each topic follows a repeatable learning cycle:

1. **Understand** — Learn the concept, purpose, and underlying principles.
2. **Recall** — Explain the concept without consulting notes.
3. **Practice** — Execute commands, inspect configurations, and complete exercises.
4. **Troubleshoot** — Investigate failures and identify their root causes.
5. **Review** — Record mistakes, clarify misunderstandings, and revisit weak areas.

## Practice Guidelines

- Understand before memorizing.
- Prefer hands-on practice over passive reading.
- Explain technical concepts in your own words.
- Verify results instead of assuming commands worked.
- Distinguish between concepts understood and tasks successfully practiced.
- Document mistakes as opportunities to improve.
- Revisit difficult topics regularly.

## Progress Tracking

Progress is measured by the ability to explain concepts, perform tasks independently, troubleshoot problems, and apply knowledge in different situations.

Completing a document alone does not indicate mastery. Practical understanding and independent application matter more.

## Guiding Principle

**The objective is not merely to remember the answer. It is to understand the system well enough to explain it, use it, and troubleshoot it.**
